# SkillCraft Technology Landing Page

A modern and interactive responsive landing page built using **HTML, CSS, and JavaScript**. This project features a fixed navigation menu, smooth scrolling, animated hover effects, responsive design, and technology-themed backgrounds.

## 🚀 Features

- Fixed Responsive Navigation Bar
- Navigation Menu Changes Style on Scroll
- Interactive Hover Effects
- Smooth Scrolling Between Sections
- Mobile-Friendly Responsive Design
- Scroll Reveal Animations
- Modern Tech-Themed Background Images
- Animated Buttons with Glow Effects
- Clean and Professional UI

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Google Fonts (Poppins)
